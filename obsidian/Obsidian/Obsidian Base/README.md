This vault is for maintaining a base configuration for Obsidian which can be shared out to other vaults easily.

It lives in the dotfiles repo (`obsidian` stow package) and is stowed to `~/Obsidian/Obsidian Base`. Other vaults in `~/Obsidian` symlink `app.json`, `appearance.json`, `hotkeys.json`, `themes/` and `snippets/` from here, so changing a setting in any of them changes it everywhere.
